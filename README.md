# Hub R
Repositório dos códigos em R usados no curso para iniciantes em 2026

## Aula 2: Data frames, tabelas e box plots

A pasta `Aula 2 - Data Frames, Tabelas e Box Plots` reúne o material completo de uma aula de cerca de 3 horas, com exemplos aplicados à Administração. Comece pelo arquivo `Roteiro da aula.md`, que traz o cronograma, as orientações ao professor, o padrão de resposta e o dicionário de dados. Os scripts usam apenas funções da instalação básica do R. Os dados, fictícios, estão digitados nos próprios scripts, que funcionam sem ler arquivos externos, inclusive no Posit Cloud.

## Aula 3: Importação, exportação e estatísticas descritivas

A pasta `Aula 3 - Importação, Exportação e Estatísticas Descritivas` reúne o material da última aula do curso, também com cerca de 3 horas. Comece pelo arquivo `Roteiro da aula.md`. Os scripts importam arquivos CSV, TXT e Excel, exportam resultados e calculam estatísticas descritivas. Além do R básico, são usados os pacotes `readxl` e `writexl`. Para levar tudo ao Posit Cloud de uma só vez, envie o arquivo `materiais_aula3.zip` pelo painel *Files > Upload*: ele é descompactado automaticamente. Se o upload falhar, o script `Baixar arquivos.R` baixa os dados diretamente deste repositório.
