# Hub R
Repositório dos códigos em R usados no curso para iniciantes em 2026

## Aula 2: Data frames, tabelas e box plots

A pasta `Aula 2 - Data Frames, Tabelas e Box Plots` reúne o material completo de uma aula de cerca de 3 horas, com exemplos aplicados à Administração. Comece pelo arquivo `Roteiro da aula.md`, que traz o cronograma, as orientações ao professor, o padrão de resposta e o dicionário de dados. Os scripts usam apenas funções da instalação básica do R, e os dados da subpasta `dados` são fictícios.
